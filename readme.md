\# Simple Digital Wedding Invitation



A clean, minimalist, and elegant digital wedding invitation card built using standard web technologies. It features a responsive layout, a gold-accented frame, classic typography, and a functional RSVP confirmation modal.



\## 🚀 Features

\* \*\*Elegant Design:\*\* Minimalist layout with gold border styling and classic typography pairings.

\* \*\*Interactive RSVP:\*\* JavaScript-powered pop-up modal to acknowledge guest responses.

\* \*\*Fully Responsive:\*\* Adapts seamlessly to both mobile devices and desktop browsers.



\## 📁 Project Structure

```text

├── index.html   # Main HTML structure and content

├── style.css    # Layout, typography, and modal animations

└── script.js    # Modal trigger logic and user interactions

```



\## 🛠️ How to Run Locally

1\. Download or clone these project files into a single folder.

2\. Open the `index.html` file directly in any modern web browser (Chrome, Safari, Edge, Firefox).



\## 🎨 Customization

\* \*\*Text \& Details:\*\* Edit the names, dates, and venue information directly inside the `index.html` file.

\* \*\*Color Schemes:\*\* Modify the background and primary accent colors in `style.css` (currently configured with `#fdfaf6` and `#b38f46` gold).
